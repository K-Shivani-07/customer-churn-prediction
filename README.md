# Customer Churn Prediction

## Project Overview

Customer churn prediction helps companies identify customers who are likely to leave the service.

This project uses machine learning techniques to analyze customer data and predict churn.

## Technologies Used

Python  
Pandas  
NumPy  
Scikit-learn  
Matplotlib  
Seaborn  

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Model Training
5. Model Evaluation

## Goal

Build a machine learning model that predicts whether a customer will churn.
